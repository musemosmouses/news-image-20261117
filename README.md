One image summing up Tuesday 17 November 2026, drawn as an editorial
front page with Python + PIL: a masthead naming the day, the lead story
(Ukraine strikes the Crimea bridge again), tankers hit near Hormuz and a
third US carrier arriving, the confirmed Xi–Trump–Putin meeting in
Shenzhen, plus a ticker with the Pentagon audit, Japan scrambling jets
and Depardieu pleading guilty. No unconfirmed allegation is stated.

- `draw.py` draws `entry.png` (1024x1024, deterministic — no clock,
  random or network; run it twice and the bytes match).
- `main.ts` (Node 22, standard library only) copies `entry.png` to
  `/output/entry.png`.
